Welcome to MAC

MBM AI Cloud — Cross the Limits

This installer will set up MAC on your PC. You'll configure it as a Host (full admin server with database, API, AI models) or a Worker (GPU compute node contributing to the cluster).

HOST
Full platform — Nginx, PostgreSQL, Redis, API, AI models
WORKER
GPU compute node — connects to Host over WiFi

Requirements

  • Docker Desktop (auto-installed if missing)
  • NVIDIA GPU with drivers installed
  • 8 GB RAM minimum · 16 GB recommended
  • WiFi/LAN connection between all nodes

Choose Your Role

How will this PC participate in the MAC network?

HOST Admin Server

Runs the complete MAC platform. All workers connect to this machine.

  • PostgreSQL database + Redis cache
  • Nginx reverse proxy + SSL
  • FastAPI backend + Web UI
  • Load balancer for worker GPUs
  • Admin dashboard + model management

WORKER GPU Node

Contributes GPU compute to an existing Host. Requires Host IP.

  • vLLM inference engine on GPU
  • Auto-registers with Host server
  • Heartbeat monitoring
  • Model auto-assigned by admin
